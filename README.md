# 观远数据分析通用 Skill

**版本：0.0.1**

面向经营分析的通用方法体系，将业务问题转化为可核验的数据口径、分析过程和决策依据。支持观远 BI 可信资产与授权通用数据工具，按任务加载相关方法。

## 分析能力

| 方法领域 | 主要内容 |
| --- | --- |
| 数据口径与查数 | 指标定义、时间范围、聚合粒度、比较、排名、比率和结果对账 |
| 经营诊断 | 异动识别、量价与结构分解、指标树分析、贡献和残差核验 |
| 探索与统计建模 | 分布、抽样、推断、回归、分类、模型诊断与验证 |
| 客户与复购 | 客户身份、有效订单、首购同期群、观察成熟度与N日复购 |
| 销量预测 | 朴素与季节朴素基线、滚动回测、误差和偏差分析 |
| 实验与影响评估 | 实验设计、效应估计、识别条件与稳健性检查 |
| 监控与决策 | 监控与告警、库存、预算、资源分配及行动方案评估 |

## 数据来源

遵循用户指定的数据来源与分析范围。有 **guancli** 和相应授权时，优先使用语义匹配的观远 BI 正式指标、页面有效条件、已确认结果及适用指标树。

没有 guancli，或相关资产不能满足分析需求时，可使用用户授权的数据库、CSV/Excel/JSON文件、API和其他分析工具。不同来源执行相同的口径、粒度、期间与完整性校验；明确说明来源切换和不可比条件。

## 使用方式

将本仓库作为一个 Skill 导入支持的宿主，或从 [Releases](https://github.com/hzzhaoyang/decidex-data-analysis/releases) 下载 `decidex-data-analysis-0.0.1.skill.zip`，通过宿主的 Skill 上传入口安装。确认当前会话已启用该 Skill。

示例问题：

- 分析本月销售下降的主要驱动因素，核对量价、结构及各项贡献。
- 基于客户订单计算首购同期群30日复购率，区分成熟与未成熟客户。
- 预测未来7天销量，用滚动回测比较朴素与季节朴素基线，并解释业务适用范围。

## 计算程序与依赖

包内提供同期群复购及销量预测基线的固定计算程序。需要 Python 3.9+ 标准库；复购计算还需 IANA 时区数据库。输入结构、执行命令和退出状态见[复购方法](references/cohort-repurchase.md)与[预测方法](references/forecast-baseline.md)。

其他统计、因果和优化方法使用宿主实际具备的引擎。方法文档不等同于已完成拟合或求解；结果解释应与实际输入、执行证据及适用条件一致。观测销售预测与潜在需求、统计关系与因果影响分别处理。
