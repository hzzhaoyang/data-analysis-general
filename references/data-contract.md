# 数据与口径：只核验会改变答案的部分

## 计算前确认度量性质

| 度量 | 聚合条件 |
| --- | --- |
| 金额、订单量等流量 | 范围互斥且口径一致才相加；明确退款、含税、币种与单位 |
| 库存、余额快照 | 取定义要求的时点或期间均值，不能跨天相加 |
| 客户/活跃人数 | 在目标期间与总体去重，不能把分组去重数或DAU直接相加 |
| 比率、均价、达成率 | 同范围汇总分子、分母后相除；权重来自真实分母 |
| 两类事实，如预算与实际 | 各自聚合到可比共同键，再对齐；不直接连接多对多明细 |

一行含义、实体键、日期事件、版本和排除条件决定能否计算。签约日与结单日、自然月与财月不能默认为同一范围。部分周期用同进度比较；截止取实际覆盖，不把昨天自动当完整日。

## 关联、缺失与完整性

先检查键唯一性与预期基数，关联后对账对象数、键覆盖及可加总量。区分重复采集、合法订单明细和冲突更新；不靠DISTINCT掩盖关联膨胀。历史组织归属按适用时点处理。

空结果、零、未采集、缺货截断和观察未成熟分别处理。工具成功不等于每个子结果成功；缺失或失败不补零。检查与本题有关的列、粒度、单位、范围与完整性，已确认事实直接复用，不为补轨迹重复查询。

TopN、份额和贡献依赖完整候选池或正式服务端计算。默认前若干行不能当全体；检查实际分页/上限和覆盖证据，少于limit也不单独证明完整。先在完整池聚合排序，再截取TopN；不同指标的TopN不能沿用同一已截断对象池。

跨期或多指标按完整业务键对齐，不按行位置连接。缺组、截断、范围冲突或一侧失败未解决时，只交付独立有效部分。计算使用原始精度，展示时再舍入；零分母保留未定义。

## 对数与证据

数值不一致时依次定位：定义/版本与默认条件 → 截止/覆盖 → 粒度/关联/权重 → 算法 → 展示舍入。固定输入与计算，不通过删条件或改显示凑一致。

保留授权的来源/结果引用、实际范围与计算依据。结论只覆盖已验证部分；区间、模型、归因或优化只有实际执行并满足前提才报告完成。真实业务证据继续随答案保留，不需要附研究书目。
