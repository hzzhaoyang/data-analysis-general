# 通用经营诊断：模式用于选证据，不直接给根因

## 驱动模式

先确认恒等式对本次口径成立。下表是跨行业的查询规划原语，不内置任何客户指标、阈值或事实。

| 问题形态 | 优先区分 | 最有用的下一证据 |
| --- | --- | --- |
| 金额变化 | 数量、单价、品类/客户组合，净额还包括退款/折扣口径 | 同范围数量/单价和组合分布；新旧对象分别列 |
| 交易或转化变化 | 流量/机会规模、逐层转化、客单/单次价值 | 用同一漏斗人群、事件顺序和观察窗核对每层分子分母 |
| 客户/会员经营 | 客户数、购买频次、单次价值；cohort与存续/新客构成 | 同cohort年龄的有效购买与观察覆盖，独立订单和身份定义 |
| 毛利/费用率变化 | 收入规模、单位经济、商品/客户结构；率的分子分母 | 收入与毛利/费用的兼容数据面，价格/成本/结构切面 |
| 目标未达 | 实际变化、目标变化、组织/定义变化 | 同版本实际/目标及修订记录；分别看金额缺口与达成率 |
| 门店/区域增长 | 同店表现、新开贡献、关闭损失和归属变化 | 两期可比对象集合及新增/退出对象；不能只报全店均值 |
| 库存/交付/供给 | 期初+流入-流出及调整是否对账；需求、产能、缺货限制 | 匹配期间的流水和快照、履约/可售状态，而非只看销量 |
| 异常监控 | 数据断点、业务事件、周期性与随机波动 | 稳定历史参照、相同季节/星期、刷新与事件时间线 |

“收入=客户数×人均频次×客单”仅在客户、订单和净收入覆盖一致时成立；退款跨期、零/负收入或订单归属不一致需要先调整定义。库存守恒式还要包含真实损耗、调拨和盘点调整，不把残差命名为损耗。

## 从总差额到有限切面

1. 记录当期、基期、总差额、单位、范围与截止；先检查偏离是否由缺数、组织或口径变化造成。
2. 有适用指标树用其正式计算并保留配置。无树时用上述模式找最短的可核验驱动关系，优先少量业务合理且互斥穷尽的维度。
3. 贡献按绝对影响、覆盖对象和持续性排序；不要因小分母增长率极高就排第一。用户给了材料性门槛就使用，没有时披露量级而非发明阈值。
4. 下钻前问：这个切面能排除哪个解释？先定位主要损失，再检查抵消收益与反例。不同维度都是同一总体的视图，不能把它们的“贡献”相加成更多损失。
5. 在分析过程中记录简明的“解释—支持证据—冲突/缺口—下一证据”。例如收入下降可能来自需求下降、断货或数据延迟；查可售/库存与刷新覆盖比继续按十个地域切片更有区分力。
6. 有限证据支持哪个层级就停在哪个层级：事实、会计贡献、关联、条件性解释或可识别因果。不用更多相关切片假装提高因果强度。

## 分解与复算

- **可加总量**：互斥完整分组的`Δ_i=当期_i-基期_i`；`sum(Δ_i)+residual=总Δ`。缺组、新增/退出要显式对齐。`Δ_i/总Δ`可为负或大于100%；总差接近0时优先给金额，不用不稳的贡献占比渲染。
- **率/均价**：`R=sum(N_i)/sum(D_i)=sum(w_i*r_i)`。需要区分组内表现与结构时，可选对称分解：`within=sum((w0+w1)/2*(r1-r0))`，`mix=sum((r0+r1)/2*(w1-w0))`，两者和为总率变化。权重来自真实分母，不任取收入/人数。某组一期分母0时，组内率未定义，不能偷填0继续分解；改报新增/退出及可加组成，或采用已明确的算法。
- **两个乘积因子**：`Y=P*Q`，对称法`P贡献=(P1-P0)*(Q0+Q1)/2`，`Q贡献=(Q1-Q0)*(P0+P1)/2`。多因子/价格数量组合需要声明交互项如何分摊，不能把二因子公式随意重复。此处是本包选择的会计约定，平台有正式算法时不擅自变更算法。
- **相对变化**：基期0时常规变化率未定义；负基期的百分比需结合绝对值说明。率的百分点变化与相对变化分开，不能把金额变化与百分数贡献混合相加。
- **组合反转**：整体与组内方向相反时先看分母权重与总体范围；“每组都改善”和“整体下降”可以同时成立。简单重加权只作标准化描述，不自动识别因果。

每次分解给出输入范围、算法、总差额、主要项和残差。残差先查截断、缺组、单位、舍入和口径；没有可解释的对账不能声称完整解释。容忍度依据源数据精度/业务标准，不内置任意百分比。

## 诊断到下一步

建议瞄准能改变的因素，不把“贡献最大分组”自动等同于最佳干预人群。先比较不行动、验证、小范围尝试等合理选项的证据、代价与可逆性；缺效果依据只给方向和验证方案，不把历史下降额当恢复收益。

数据修复与业务干预分别建议；刷新故障时优先恢复可信数据，不能建议促销掩盖缺数。若新证据消除了异常，撤回原异常驱动的建议。无正式行动资产时可保留有条件的业务候选，不能编造actionType或声称已派发执行。
