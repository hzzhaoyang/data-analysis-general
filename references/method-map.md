# 问题、知识前提与方法选择

遇到跨方法问题或不确定该读哪份参考时使用此表；普通查数不需加载全表。方法共享前提，任务不是必须串行经过的阶段。

| 方法 | 输入与知识依赖 | 执行入口 | 验证与可支持结论 |
| --- | --- | --- | --- |
| M01 正式指标查数/比较 | 企业定义、粒度、可加性、期间/版本与覆盖 | 宿主已授权的指标、数据库或文件工具；[数据契约](data-contract.md)、[数据来源与资产绑定](asset-binding.md) | 核对实际参数/粒度/子项状态；支持同口径事实，不支持根因 |
| M02 量价/结构/指标树诊断 | M01事实面＋恒等式、权重与完整对象集合 | 平台适用归因能力或[诊断方法](diagnosis.md)；本包无固定分解脚本 | 总差额勾稽、交互与残差；会计贡献不等于干预效果 |
| M03 分布/关联探索 | 对象级观测、抽样/选择机制、缺失、测量尺度 | [探索建模](exploration-modeling.md)；用已授权统计工具 | 分位数和总体范围正确，反例/分层；只作描述或关联 |
| M04 推断/回归/分类 | M03数据面＋独立/配对/集群单位、模型和标签、划分与校准 | [探索建模](exploration-modeling.md)；本包无固定拟合引擎 | 实际估计/诊断/留出结果；回归预测不能自动支持政策因果 |
| M05 首购同期群复购 | 身份/独立订单/有效状态、首购历史、观察窗、删失；终值边界另需稳定性证明 | [复购方法卡](cohort-repurchase.md)和固定脚本 | 分子分母、成熟/未成熟、条件性边界；缺历史拒算；不等于CLV或发券增量 |
| M06 规则序列预测基线 | 时间索引、频率/季节依据、目标与跨度、完整期、缺货及修订 | [预测方法卡](forecast-baseline.md)和固定脚本 | 朴素/季节朴素同起点滚动比较；快照回测不证明历史时点可得性，不输出因果或决策最优 |
| M07 实验/非随机影响评估 | 估计对象、处理/对照、随机单位或识别假设、时间与干扰 | [专项方法](specialist-methods.md)；本包无固定估计引擎 | 质量/护栏、效应量/区间、稳健性；识别不足只报告观察变化 |
| M08 监控与告警 | M01可信历史＋季节/分母规模、稳定期、误报代价 | [专项方法](specialist-methods.md)；本包无固定监控引擎 | 告警不等于目标未达或根因；方法/阈值需项目依据 |
| M09 资源/库存/预算决策 | 目标、可控变量、成本、可行约束及合格需求/效果输入 | [决策方法](decision.md)；本包无固定求解引擎 | 求解状态、可行性、留出业务损失；M06误差小不自动证明收益高 |
| M10 行业解释与交付 | M01—M09相关事实＋真实业务流程/约束及来源 | 主入口交付要求、授权业务知识；无内置完整行业SOP库 | 业务角色核对解释/用途，区分草案、执行与效果 |

## 关系决定下一步，不能越级

- M01只需基础事实，不默认启动M03/M04或独立Review。只有明确任务和所需输入具备时才进入后续方法。
- M02可以产生待验证解释，需M07识别条件才能称行动因果；更多切片不能替代对照设计。
- M05是已观测购买行为；未来交易/CLV需要另建客户模型并时间留出，不能把M05改名当预测。
- M06提供预测基线；用于M09还需提前期、库存位置和损失。促销方案改变需求时，还要有M07或其他可辩护的响应依据。
- 数学/概率约束计算与不确定性；数据建模决定输入是否有效；行业机制决定变量与解释；治理/复现决定适用范围。缺输入或执行器时交付事实/方法计划与精确缺口，不声称方法已运行。

M05/M06需具备真实输入和允许执行的Python环境；其余方法按宿主实际能力执行。是否被采用、结果正确与业务收益分别验证。
